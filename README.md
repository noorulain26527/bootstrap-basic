# Bootstrap Components Practice

A basic frontend project created using HTML, CSS, and Bootstrap. This project focuses on practicing common Bootstrap components and learning how to build a clean and responsive website layout.

## 🚀 Features

- Responsive Bootstrap Navbar
- Bootstrap Cards
- Image Slider / Carousel
- Styled Buttons
- Responsive Layout
- Bootstrap Components
- Clean and Simple UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap
